Coastal Dental & Maxillofacial Center Website

Coastal Dental & Maxillofacial Center is a modern dental clinic dedicated to providing high-quality oral healthcare with a patient-first approach. The clinic offers preventive care, cosmetic dentistry, restorative procedures, orthodontics, dental implants, root canal treatment, tooth extractions, and oral surgery.

This internship project was developed to create a professional, responsive, and user-friendly website for the clinic. The website includes service information, doctor profiles, online appointment booking, Google Maps integration, patient testimonials, FAQs, and contact details.

  • CSS3
  • JavaScript
  • Responsive Web Design
  • Git & GitHub
  • Lovable AI
  • Google Maps Integration
  • WhatsApp Chat Integration
